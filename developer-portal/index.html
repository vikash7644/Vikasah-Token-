01 / GET STARTED

Your first VKT integration

Connect to a wallet provider, verify the active network, then read token data. Do not request or store a seed phrase or private key.

JavaScript · ethers v6
import { BrowserProvider, Contract } from "ethers";

const VKT_ADDRESS = "SET_VERIFIED_TESTNET_CONTRACT_ADDRESS";
const ERC20_ABI = [
  "function name() view returns (string)",
  "function symbol() view returns (string)",
  "function decimals() view returns (uint8)",
  "function balanceOf(address) view returns (uint256)"
];

async function readVkt() {
  if (!window.ethereum) throw new Error("Install a compatible wallet");
  const provider = new BrowserProvider(window.ethereum);
  const network = await provider.getNetwork();
  if (network.chainId !== 97n) {
    throw new Error("Switch to BNB Smart Chain Testnet (chain ID 97)");
  }
  const signer = await provider.getSigner();
  const token = new Contract(VKT_ADDRESS, ERC20_ABI, provider);
  const [name, symbol, decimals, balance] = await Promise.all([
    token.name(), token.symbol(), token.decimals(),
    token.balanceOf(await signer.getAddress())
  ]);
  return { name, symbol, decimals: Number(decimals), balance };
}

Important: The contract address is intentionally a placeholder. VKT has not been deployed or verified on testnet yet. Never send funds to a guessed address.

03 / GUIDES

Integration guides

Use these patterns as a starting point. They are examples, not a live API or payment guarantee.

A

Wallet connection

Use an EIP-1193 provider, request account access only after a user action, and handle account/network changes.

B

Accepting a VKT payment

Request an explicit transfer from the payer, wait for a receipt, then verify the token Transfer event against the expected contract, recipient and amount.

C

Payment verification

Verify chain ID, successful receipt, token contract, Transfer event fields, amount and confirmations. Add server-side replay protection before real orders.

D

Merchant checkout

Bind each invoice to a unique order identifier on your backend. Browser storage is local convenience, not a shared source of truth.
